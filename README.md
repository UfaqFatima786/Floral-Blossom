# 🌸 Floral Blossom

A modern, elegant, and fully responsive flower shop website built using **HTML5, CSS3, Bootstrap 5, and JavaScript**. Floral Blossom provides a beautiful online experience for exploring bouquets, floral arrangements, and decorative flowers through a clean, visually appealing interface.

## 📂 GitHub Repository

# 📖 Project Overview

**Floral Blossom** is a responsive flower shop website designed with a modern aesthetic and smooth user experience. The website features attractive layouts, elegant typography, engaging animations, and organized product displays that create a pleasant online shopping experience for flower lovers.
