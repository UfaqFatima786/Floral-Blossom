# 🌸 Floral Blossom

A modern, elegant, and fully responsive flower shop website built using **HTML5, CSS3, Bootstrap 5, and JavaScript**. Floral Blossom is designed to provide a beautiful online shopping experience where users can explore stunning flower collections, bouquets, floral decorations, and special offers with an attractive and responsive interface.

---

## 🌐 Live Demo

🔗 **Website:** https://floral-blossom.netlify.app/

📂 **GitHub Repository:** https://github.com/UfaqFatima786/Floral-Blossom

---

# 📖 About The Project

Floral Blossom is a responsive flower shop website created with a modern and elegant design. The project focuses on delivering a clean user interface, responsive layouts, and interactive features to enhance the user experience. Visitors can browse different flower categories, featured bouquets, floral decorations, customer testimonials, and contact information through a beautifully designed website.

This project was developed to practice responsive web development, Bootstrap components, JavaScript interactivity, and UI/UX design principles.
